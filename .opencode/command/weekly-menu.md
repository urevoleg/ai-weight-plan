---
description: Составить меню на следующую неделю (вс–сб) и записать его в Google Calendar (аргумент: номер недели, по умолчанию следующая)
---

Прочитай AGENTS.md (раздел 5.1) и site/plan.md. Аргументы команды: $ARGUMENTS

1. Определи неделю (вс–сб): по аргументу или неделю, которая начинается с ближайшего воскресенья.
2. Тип каждого дня — по календарю тренировок на эту неделю; если календарь недоступен — по шаблону недели. Цели — из AGENTS.md, раздел 4 (с учётом правок плана).
3. Составь меню по правилам раздела 5.1 и предпочтениям (без овсянки на молоке, без тофу и бурого риса; овсяноблин, басмати, гречка, творожная запеканка, тыквенная каша). Сохрани в `site/menus/week-NN.json` по образцу `site/menus/_template.json`. Запусти `python3 scripts/validate_menu.py site/menus/week-NN.json`: ккал должны быть в пределах ±100 от цели, белок ≥ 140 г, без мяса, обычная рыба 2–3 раза, Магуро 3–4 раза.
4. Покажи меню пользователю по дням (приёмы, ккал, белок) и остановись.
5. Запись в календарь — только после прямого «да» пользователя в чате. Автоматический субботний запуск пишет сам (см. AGENTS.md 5.1). После «да»: удали старые события с маркером `[ai-weight-plan week-NN]` этой же недели и события с маркером предыдущей недели на даты нового окна (1 ноября — воскресное меню недели 2 вместо меню недели 1). Создай 5 приёмов на каждый день окна вс–сб (эмодзи, граммовка, маркер `[ai-weight-plan week-NN]`), без гостей и напоминаний. События без маркера не трогай.
6. Если календарь недоступен — `.ics`: `python3 scripts/menu_to_ics.py site/menus/week-NN.json > site/menus/week-NN.ics`.
7. Закоммить `site/menus/`: `Menu week NN`, запушь в `main`.
